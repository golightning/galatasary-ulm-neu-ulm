# Zertifikate
Dieses Verzeichnis enthält die Zertifikate für Apple Wallet und Google Wallet.
Diese Dateien NICHT in Git einchecken!

## Benötigte Dateien:
- `pass.pem` - Apple Pass Zertifikat
- `pass-key.pem` - Apple Pass Private Key
- `wwdr.pem` - Apple WWDR Zertifikat
- `google-sa-key.json` - Google Service Account Key
